# Accessibility engine: 50-improvement delivery ledger

Started 2026-10-22 from `eff2da8`. The active objective is to implement and verify **all 50** improvements below. Previous deliveries are the baseline and are not credited toward these 50. Status and evidence are maintained in [the machine-readable ledger](evidence/accessibility-50-status.json).

Research establishes requirements, not proof of our implementation. The engineering choices below combine observed repository gaps with these primary sources:

- [PDF Association Matterhorn Protocol 1.1](https://pdfa.org/wp-content/uploads/2021/04/Matterhorn-Protocol-1-1.pdf): separate machine-checkable failures from matters needing human judgment.
- [ISO 32000-2 document interchange errata](https://pdf-issues.pdfa.org/32000-2-2020/clause14.html) and [text errata](https://pdf-issues.pdfa.org/32000-2-2020/clause09.html): structure/content relationships, text operators, fonts and Unicode. PDF 2.0 findings inform version-aware handling; they are not a claim of PDF/UA-2 support.
- W3C techniques for [reading/tab order (PDF3)](https://www.w3.org/WAI/WCAG22/Techniques/pdf/PDF3), [tables (PDF6)](https://www.w3.org/WAI/WCAG22/Techniques/pdf/PDF6), [OCR (PDF7)](https://www.w3.org/WAI/WCAG22/Techniques/pdf/PDF7), [headings (PDF9)](https://www.w3.org/WAI/WCAG22/Techniques/pdf/PDF9), [links (PDF11)](https://www.w3.org/WAI/WCAG22/Techniques/pdf/PDF11), [forms (PDF12)](https://www.w3.org/WAI/WCAG22/Techniques/pdf/PDF12), and [bookmarks (PDF2)](https://www.w3.org/WAI/WCAG22/Techniques/pdf/PDF2). These are techniques, not certification criteria by themselves.
- [Apache PDFBox 3.0.8 PDFStreamEngine source](https://raw.githubusercontent.com/apache/pdfbox/3.0.8/pdfbox/src/main/java/org/apache/pdfbox/contentstream/PDFStreamEngine.java): implementation behavior must be distinguished from lexical source operations.

Completion requires an actual engine improvement, targeted positive/adversarial tests, saved-PDF verification where relevant, and appropriate real-document replay. Preserve source appearance, editable controls and raw findings. Do not mark an item resolved by weakening a gate or replacing its requested capability with rejection. Human review remains required for final document acceptance.

## Selected improvements

| ID | Area / improvement | Acceptance evidence required |
| --- | --- | --- |
| A01 | Native operators: **Lexical operator indices**. Keep source operator indices exact when PDFBox dispatches virtual TD/TL operations. | Mixed positioning/text fixture indices equal an independent PDFStreamParser token walk. |
| A02 | Native operators: **Quoted text operators**. Treat single-quote and double-quote text showing as one source operation each. | Quote operators decode complete text once and subsequent native tags own the correct glyphs. |
| A03 | Native operators: **Nested stream identity**. Report Form XObject invocation paths separately from page text operators. | Nested/reused Forms carry stable invocation identities; no child operator impersonates page text. |
| A04 | Native operators: **Native Form XObject tagging**. Tag text in nested and reused Form XObjects with invocation-specific ownership. | Saved text in two differently transformed invocations has correct owners and unchanged pixels. |
| A05 | Native operators: **Stream-scoped MCR emission**. Write stream references and scoped ParentTree entries for non-page content. | Identical MCID numbers in different streams resolve to their own structure elements. |
| A06 | Native operators: **Standalone list marker attachment**. Attach a marker-only source operator to Lbl and following content to LBody. | Separate marker/body operands yield nonempty saved Lbl and LBody without moving glyphs. |
| A07 | Native operators: **Array-based list marker splitting**. Split qualified TJ list markers while retaining all positioning adjustments. | Mixed string/number TJ arrays preserve advances, bytes and distinct label/body ownership. |
| A08 | Native operators: **Compound text-node attachment**. Partition one source text operation across multiple intended label/value nodes. | Booklet label/value examples attach to exact intended nodes; spacing and geometry are unchanged. |
| A09 | Native operators: **Glyph-to-byte mapping**. Expose verified byte boundaries for multibyte codes, ligatures and Unicode sequences. | Splitting never bisects a font code or Unicode mapping; ambiguous boundaries are rejected. |
| A10 | Native operators: **Optional-content preservation**. Retain optional-content wrappers during retagging. | Default visibility and alternate layer states render identically; generated MCIDs remain balanced. |
| A11 | Semantic content: **Authored replacement text**. Carry valid source ActualText/expansion semantics through native rebuilding. | Authored ligature and abbreviation replacement survives without duplicating or suppressing unrelated text. |
| A12 | Semantic content: **Artifact subtype preservation**. Retain evidenced pagination/background artifact properties without hiding meaningful content. | Saved pagination/artifact metadata survives, while identically styled body text remains semantic. |
| A13 | Geometry: **CropBox origin handling**. Normalize extraction, matching and saved geometry for nonzero/negative crop origins. | Shifted-crop fixtures attach all intended text and retain page geometry and pixels. |
| A14 | Geometry: **UserUnit handling**. Use a consistent coordinate convention for PDFs with non-default UserUnit. | Scaled-unit fixtures preserve coordinates across text, annotations and matching without double scaling. |
| A15 | Geometry: **Rotated-page reading order**. Order semantic content in the actual display frame across page rotations. | Rotated multicolumn pages have expected saved order at 0/90/180/270 degrees. |
| A16 | Semantic content: **Label/value paragraph boundaries**. Prevent paragraph merging across adjacent label/value columns. | Booklet launch details and acronym rows retain distinct identities and logical pair order. |

| A20 | Headings: **Section hierarchy consistency**. Keep section containers consistent with corrected heading ranks and membership. | Saved nested sections agree with the approved outline after heading demotion and rank refinement. |
| A21 | Saved validation: **Existing MCID references**. Verify that every saved MCR points to a real marked-content sequence. | Deleting or changing a sequence makes saved comparison fail, even when its MCR dictionary remains. |
| A22 | Saved validation: **Nonempty content attachment**. Require meaningful owned content rather than an empty MCID wrapper. | Empty and whitespace-only wrappers cannot satisfy intended nonempty text attachment. |
| A23 | Saved validation: **Exclusive painted ownership**. Detect duplicate and foreign ownership of painted source content. | Wrong-owner and multiply-owned glyph mutations fail despite unchanged structure IDs. |
| A24 | Saved validation: **Scoped reciprocal ParentTree**. Verify reciprocal ownership across page, Form and annotation scopes. | Cross-stream and annotation-key mutations fail; valid reused MCIDs in separate scopes pass. |
| A25 | Saved validation: **Text completeness proof**. Compare intended source identities against the actual saved glyph coverage. | Partial substring matches cannot pass complete text; bounded replacement-text exceptions carry proof. |
| A26 | OCR: **OCR coordinate transforms**. Map OCR coordinates through crop, rotation and render scale exactly once. | Known image text boxes land correctly on rotated/cropped pages at multiple render resolutions. |
| A27 | OCR: **Image-only tagged text layer**. Insert a tagged invisible text layer for accepted OCR on image-only pages. | Official poster and synthetic scans expose saved text with complete ownership and unchanged images. |
| A28 | OCR: **Mixed-page OCR attachment**. Attach OCR-only regions without duplicating native text or losing conflicts. | Booklet mixed page gains OCR attachments; overlapping native/OCR conflicts remain explicit review tasks. |
| A29 | OCR: **OCR Unicode font coverage**. Embed verified OCR fonts and preserve Unicode for characters outside the first font. | Accents, symbols and missing-glyph cases have correct extracted text or explicit failure, never replacement boxes. |
| A30 | OCR: **OCR uncertainty workflow**. Carry word-level uncertainty and corrections through to saved output qualification. | Low-confidence text cannot be silently accepted; hash-bound corrections change only intended text metadata/layer. |
| A31 | Fonts: **Missing CIDToGIDMap repair**. Qualify missing mappings using the existing embedded TrueType program. | Booklet mapping failures reduce only with proven used-code/GID equivalence and pixel preservation. |
| A32 | Fonts: **Symbol Unicode repair**. Repair supported symbolic-font Unicode mappings using verified glyph evidence. | Wingdings-like cases produce correct Unicode for observed glyphs; unsupported ambiguity stays unresolved. |

| A37 | Navigation: **Rotated and quad-point links**. Associate rotated and multiline link geometry in a consistent coordinate frame. | QuadPoints/rotation fixtures bind the correct anchor and preserve actions; nearby text is excluded. |

| A41 | Tables: **Overlapping span detection**. Detect and resolve inconsistent row/column spans before inventing grid positions. | Overlapping spans generate a bounded repair/review result; valid merged grids serialize unchanged. |
| A42 | Tables: **Mixed row and column headers**. Improve corner and multirow header association with explicit scope evidence. | Reviewed mixed-header fixtures expose correct Headers relations with no unrelated header targets. |
